# 公募基金营销任务三角色首页设计

> 版本：v0.1  
> 日期：2026-08-06  
> 范围：手机端 Web 首页

## 1. 首页设计原则

首页不是宣传页，而是每个角色进入公募基金营销任务平台后的工作台。首屏优先回答三个问题：

1. 我现在最应该处理什么？
2. 当前任务流转有没有风险？
3. 我下一步能直接做什么？

手机端首页采用“顶部身份区 + 核心指标 + 关键待办 + 最近任务”的结构。不同角色复用相同信息骨架，但内容和操作权限不同。

底部导航首版建议为 4 个入口：

```text
首页 / 任务 / 消息 / 我的
```

运营可在首页放置“创建任务”主按钮；普通用户可在首页放置“去领取”主按钮；机构首页不放创建入口。

## 2. 运营首页

运营首页的目标是快速发现营销任务的待处理事项和流转风险，并能直接进入创建、审核、监控。

### 2.1 首屏结构

```text
顶部：运营姓名 / 当前角色 / 消息入口
主操作：创建任务
核心待办：待发布、待审核、异常、即将截止
任务概览：可领取、进行中、已完成、已下架
风险提醒：无人领取、待审核积压、超时任务
快捷入口：任务管理、审核台、流转监控、数据看板
最近任务：最近创建或最近发生变化的任务
```

### 2.2 核心模块

| 模块 | 展示内容 | 点击后进入 |
| --- | --- | --- |
| 今日待办 | 待发布数、待审核数、异常数、即将截止数 | 对应筛选后的任务列表 |
| 创建任务 | 固定主按钮，建议悬浮或顶部显著按钮 | 创建任务页 |
| 流转风险 | 无人领取、提交超时、审核积压、任务过期 | 流转监控页 |
| 任务概览 | 可领取、进行中、已完成、已下架 | 任务管理页 |
| 审核队列 | 最新待审核提交，最多展示 3 条 | 审核台或提交详情 |
| 最近任务 | 最近创建、发布、下架、完成的任务 | 任务详情 |

### 2.3 首屏建议布局

```text
[顶部栏] 你好，运营A                         [消息]

[主按钮] + 创建任务

[今日待办]
待发布 8    待审核 24
异常 3      即将截止 12

[流转风险]
无人领取任务 5 个
待审核超过 24 小时 7 个

[快捷入口]
任务管理 | 审核台 | 流转监控 | 数据看板

[最近任务]
任务标题 / 基金产品 / 机构 / 平台 / 状态 / 更新时间
```

### 2.4 运营首页关键动作

- 创建任务
- 进入待发布列表
- 进入待审核列表
- 处理异常任务
- 查看某个基金产品、机构或平台的任务流转

### 2.5 空状态

如果没有待处理事项，首页不展示空白，而展示：

```text
当前没有待处理任务
你可以创建新任务，或查看任务管理中的历史任务。
```

主按钮仍然保留“创建任务”。

## 3. 机构首页

机构首页的目标是查看本机构相关公募基金营销任务的进度、结果和风险。机构首版只查看，不创建、不编辑、不审核。

### 3.1 首屏结构

```text
顶部：机构名称 / 当前账号 / 消息入口
任务总览：本机构营销任务总数、进行中、已完成、异常
进度看板：领取率、提交率、通过率、完成率
重点关注：即将截止、超时、待审核、异常任务
任务列表：本机构最近更新任务
快捷入口：任务列表、流转监控、数据看板
```

### 3.2 核心模块

| 模块 | 展示内容 | 点击后进入 |
| --- | --- | --- |
| 本机构总览 | 任务总数、进行中、已完成、异常 | 本机构任务列表 |
| 流转进度 | 领取率、提交率、审核通过率、完成率 | 数据看板 |
| 风险提醒 | 即将截止、已超时、无人领取、异常任务 | 流转监控 |
| 最近任务 | 最近更新的本机构任务 | 任务详情 |
| 结果概览 | 已完成任务、审核通过数量、通过率 | 结果看板 |

### 3.3 首屏建议布局

```text
[顶部栏] 机构名称                            [消息]

[本机构任务]
总任务 120   进行中 36
已完成 78    异常 6

[进度]
领取率 82%   提交率 64%
通过率 91%   完成率 65%

[重点关注]
即将截止 9 个
超时任务 2 个
待审核提交 18 个

[快捷入口]
任务列表 | 流转监控 | 数据看板

[最近任务]
任务标题 / 基金产品 / 平台 / 状态 / 完成进度 / 更新时间
```

### 3.4 机构首页关键动作

- 查看本机构任务列表
- 查看某个任务详情
- 查看任务提交结果
- 查看流转监控
- 查看机构看板

### 3.5 机构可见数据边界

机构首页只能展示关联到本机构的数据：

- 可见：任务基本信息、基金产品、平台、状态、领取进度、提交数量、审核后的结果、流转记录。
- 默认不可见：其他机构任务、普通用户敏感信息、未审核原始材料。
- 待确认：机构是否能查看用户提交的原始材料。

### 3.6 空状态

如果本机构暂无任务：

```text
暂无关联任务
运营发布与你相关的任务后，会在这里展示进度和结果。
```

不展示“创建任务”按钮。

## 4. 普通用户首页

普通用户首页的目标是快速领取合适的营销任务，并及时处理自己已经领取的任务。

### 4.1 首屏结构

```text
顶部：用户昵称 / 用户状态 / 消息入口
主操作：去领取任务
我的任务：待提交、待审核、返工中、已完成
推荐任务：可领取任务，按截止时间和匹配度排序
提醒：即将截止、返工、审核结果
收益或成长信息：可选，根据业务是否存在奖励机制决定
```

### 4.2 核心模块

| 模块 | 展示内容 | 点击后进入 |
| --- | --- | --- |
| 我的待办 | 待提交、返工中、即将截止 | 我的任务 |
| 去领取任务 | 主按钮或推荐列表入口 | 任务大厅 |
| 推荐任务 | 可领取任务，展示标题、基金产品、平台、截止时间、名额 | 任务详情 |
| 审核动态 | 待审核、已通过、被驳回 | 我的任务详情 |
| 完成情况 | 已完成数量、通过率、连续完成天数 | 个人看板 |

### 4.3 首屏建议布局

```text
[顶部栏] 你好，用户A                         [消息]

[我的任务]
待提交 3    返工中 1
待审核 5    已完成 28

[提醒]
2 个任务今天截止
1 个任务需要返工

[主按钮] 去领取任务

[推荐任务]
任务标题 / 基金产品 / 平台 / 截止时间 / 剩余名额
任务标题 / 基金产品 / 平台 / 截止时间 / 剩余名额

[最近动态]
审核通过 / 驳回原因 / 提交成功
```

### 4.4 普通用户首页关键动作

- 去任务大厅领取任务
- 继续提交未完成任务
- 查看返工原因并重新提交
- 查看审核结果
- 查看已完成任务

### 4.5 空状态

如果用户没有领取任务：

```text
你还没有领取任务
去任务大厅看看当前可领取的任务。
```

保留“去领取任务”主按钮。

如果任务大厅没有可领取任务：

```text
暂无可领取任务
有新任务发布后会第一时间通知你。
```

## 5. 首页指标口径

| 指标 | 口径 |
| --- | --- |
| 待发布 | `tasks.status = 待发布` |
| 可领取 | `tasks.status = 可领取` 且未满额且未过期 |
| 进行中 | 已有领取记录且任务未完成、未下架、未过期 |
| 待审核 | `task_claims.status = 待审核` |
| 返工中 | `task_claims.status = 返工中` |
| 异常 | 无人领取、超时、待审核积压、被多次驳回等规则命中 |
| 完成率 | 已完成任务数 / 发布任务数 |
| 领取率 | 已领取名额 / 任务总名额 |
| 提交率 | 已提交领取记录数 / 已领取记录数 |
| 通过率 | 审核通过数 / 已审核提交数 |

MVP 可以先使用实时查询；当任务量增长后，再改为定时聚合或事件驱动统计。

## 6. 首页差异总结

| 角色 | 首页核心问题 | 主按钮 | 默认列表 |
| --- | --- | --- | --- |
| 运营 | 哪些营销任务需要我处理，哪里有风险？ | 创建任务 | 待发布、待审核、异常、最近任务 |
| 机构 | 我机构相关营销任务进展如何，结果怎么样？ | 无 | 本机构任务、重点关注、最近任务 |
| 普通用户 | 我该领取什么，我已领取的任务要不要处理？ | 去领取任务 | 我的待办、推荐任务、最近动态 |

## 7. MVP 首页范围

MVP 首页建议先做这些内容：

- 运营：首页待办、创建任务、审核队列、最近任务。
- 机构：首页总览、重点关注、最近任务。
- 普通用户：我的任务、去领取任务、推荐任务、提醒。

数据看板可以先做简版数字卡片，复杂趋势图放到 M3。
