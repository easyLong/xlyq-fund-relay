# 兼职人员工作台设计

## 1. 核心目标

兼职人员打开页面后，应该在 10 秒内知道：

- 有没有适合自己的任务
- 我已经领取了哪些任务
- 下一步要提交什么
- 当前提交是否在审核
- 被退回时需要补什么
- 通过后积分何时到账

## 2. 页面结构

```text
兼职工作台
├── 积分摘要：可用积分、可兑换金额、冻结积分
├── 任务状态统计：待处理、审核中、已通过、可领取
├── 我的任务筛选：待处理 / 审核中 / 已完成 / 全部
├── 任务大厅：平台、截止时间、奖励、名额、合规要求
└── 任务详情：任务说明、提交要求、链接表单、审核意见、流程进度
```

## 3. 兼职人员状态流

```text
可领取
→ 已领取/待提交
→ 提交结果
→ 审核中
→ 已通过/积分到账
```

审核退回时：

```text
审核中
→ 待补充
→ 重新提交
```

## 4. 任务详情必须展示

- 任务目标和内容场景
- 发布平台
- 截止时间和剩余时间
- 奖励积分及兑换规则
- 执行名额和当前进度
- 必须提交的字段
- 合规禁用词和内容限制
- 发布链接
- 内容说明或截图
- 独立任务提交详情页
- 发布截图预览、删除和最多 3 张限制
- 提交记录版本化，审核退回后可重新提交
- 审核状态和退回原因

## 5. 当前第一版已实现

- 个人任务接口 `/api/v1/users/:userId/tasks`
- 任务大厅
- 我的任务状态筛选
- 待提交、审核中、已完成状态
- 真实发布链接填写
- 内容说明填写
- 审核退回意见展示
- 审核通过后积分刷新
